# Distributed-Computing-Final

Final project for Distributed Computing.

Hospitals often struggle to share patient records between departments and facilities because their record systems don't communicate with each other. This leads to repeated tests and delays in treatment. This project is a small client-server prototype that shows how a distributed system could solve this: multiple departments use **remote procedure calls (RPC)** to read and update patient records stored on one shared central server. The server handles concurrent requests with **multithreading** and protects the shared records with **mutual exclusion**.
